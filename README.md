# Kizaah Josh V. Dela Cruz — IT Professional Portfolio

Architectural monochrome portfolio with dynamic administrative editor, custom skills manager, flexible showcase, and live HUD widgets.

## Features
- **Monochrome & Precision UI**: Obsidian aesthetic with luminous accents (`#00f59b`, `#38bdf8`) and natural profile imagery.
- **Dynamic Content Management**: Fully editable hero, skills categories, projects, experience, and hero code card.
- **Automatic Flexibility**: Hidden details in admin automatically hide on the portfolio.
- **Pure Static Edge Ready**: Optimized for Vercel, GitHub Pages, or any static hosting.

## Local Development & Admin
To run the local server with the admin editor:
```bash
node server.js
```
Then visit:
- **Portfolio**: [http://localhost:3000](http://localhost:3000)
- **Admin Editor**: [http://localhost:3000/admin](http://localhost:3000/admin)
